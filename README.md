# annika futch · after hours lab

Portfolio site. Plain HTML and CSS, hosted free on GitHub Pages.

## Files

| File | What it is |
| --- | --- |
| `index.html` | Homepage |
| `fig-01.html` | FIG. 01 The Data Room Engine |
| `css/style.css` | All colors, fonts and layout. The colors are at the very top |
| `assets/` | Every image (disco balls, collider, grain, charts and more) |

## Quick edits (from any browser, even your phone)

1. Open the file on github.com and click the pencil icon.
2. Change the words between the tags, for example the text inside `<p class="small">…</p>`.
3. Click **Commit changes**. The live site updates in about 1–10 minutes.

## Things to fill in

Search each HTML file (Cmd+F on github.com) for these and replace them:

- `RESUME-LINK-HERE` → your Google Drive resume link (shared as "Anyone with the link can view")
- `EMAIL-HERE` → your email address
- `LINKEDIN-LINK-HERE` → your LinkedIn URL
- `[your favorite line] / [your book]` → a short quote and its book

## Moving things

Every positioned element has `--x`, `--y` and `--w` in its `style`. Those are the same X, Y and width numbers as the build guide, measured from the top-left of that section. Change the number, commit, done.

## Swapping photos

Upload your photo into `assets/` (Add file → Upload files), then change `photo-placeholder.png` in `index.html` to your file name.
