FIG. 01 · Systems + governance · May 2025–now

The Data Room Engine

146 spreadsheet layouts. 15 companies. Zero company-specific code.

Role

AI Systems and Governance Lead, Rockmont Partners

Timeline

May 2025 to present

Tools

Python, local LLMs, config-driven extraction

Constraint

No data leaves the building

every number → its source cell

client names redacted, obviously ♡

The problem

Rockmont's data room held 16,000+ documents. Every portfolio company reported in its own spreadsheet format, so monitoring them meant opening files one by one.

Cloud AI tools were off the table. Private-company financials cannot leave the firm, so the system had to run entirely on local hardware.

the constraint that shaped every design decision

The approach

Governance layer · local only · source-traceable

Input

16,000+ documents

→

Discover

Local LLM reads new layouts

→

Extract

One engine, 146 configs

→

Output

Data points linked to source cells

Instead of writing code per company, each layout is described in a small config file. One engine reads them all. Every extracted number keeps a pointer back to the exact cell it came from, so any figure can be audited in seconds.
